# Vanguard Keyboard Outsider

![Outsider](https://github.com/DreaM117er/Paicorea43-1/blob/main/pic/info2.png)

Plank with Explorer Keyboard module parts.

* Keyboard Maintainer: [DreaM117er](https://github.com/DreaM117er)
* Keymap Supported: QMK, VIAL

## Building the firmware

Make example for this keyboard (after setting up your build environment):

**ProMicro (like) supported:**

    make explorerkb/outsider:[KEYMAP]

or

    qmk compile -c -kb explorerkb/outsider -km [KEYMAP]

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
